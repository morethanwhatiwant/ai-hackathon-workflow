# AI Hackathon Codex Workflow

특정 도메인의 문제나 답안을 포함하지 않는 범용 Codex 협업 워크플로다. 요구사항 추적, 생성과 독립 검증의 분리, 사실에 기반한 테스트·결정 기록을 통해 제한된 180분 안에 정확하고 실제 사용 가능한 결과를 만드는 것이 목적이다.

## 사용 순서

허용된 환경에서 다음 순서로 사용한다.

1. 허용된 공개 저장소를 **Clone**한다.
2. `AGENTS.md`를 읽고 최신 시험 가이드와 충돌하는 경우 최신 가이드를 우선한다.
3. 제공된 데이터와 규정을 조사하되 실제 시험 자료·정답·비공개 정보를 저장소에 옮기지 않는다.
4. `REQUIREMENTS_TEMPLATE.md`로 요구사항, 제약, 가정, Edge Case와 테스트를 연결한다.
5. 실제 데이터를 연결해 구현하고 `TESTING_GUIDE.md`에 따라 생성과 독립 검증을 분리한다.
6. `AI_COLLABORATE_TEMPLATE.md`와 `DECISION_LOG_TEMPLATE.md`에 객관적 근거와 사람의 최종 결정을 기록한다.
7. `CHECKLIST.md`를 시간 구간별로 완료하고 검증된 결과만 제출한다.

## 시험 조건과 금지사항

- 총 180분 안에 저장과 제출을 끝낸다. 제출 확정 후에는 수정하지 않는다.
- 후속 서술형은 6문항, 문항당 5분이며 본인이 작성한다. 후속 서술형에 AI를 사용하거나 복사·붙여넣기 하지 않는다.
- Codex는 허용 모델만 사용하고 시험 중 업데이트하지 않는다. Claude Code, Astra, 기타 외부 AI는 금지한다.
- 허용된 공개 저장소는 Clone할 수 있지만 외부 완성 결과물로 과제를 대체할 수 없다.
- 총 저장공간은 10GB 이하로 유지하고 RAM 16GB 환경을 고려한다.
- 시험 중 외부 AI 연결, 외부 전송 자동화, 답변 자동 생성 기능을 포함하지 않는다.

> **중요: 실제 시험 환경에서는 Git Push를 절대 하지 말고 어떤 산출물도 외부로 전송하지 않는다.** 이 공개 템플릿의 사전 준비·배포와 실제 시험 중 작업은 엄격히 구분한다.

실제 시험 자료, 정답, 비공개 정보, 시험 중 생성한 산출물은 GitHub나 다른 외부 서비스에 업로드하지 않는다. 토큰과 비밀번호도 파일·로그·커밋에 저장하지 않는다.

## 포함 문서

- `AGENTS.md` — 단계별 Codex 실행 규칙
- `CHECKLIST.md` — 180분 시간대별 체크리스트
- `TESTING_GUIDE.md` — 실패·변경·회귀를 포함한 검증 지침
- `AI_COLLABORATE_TEMPLATE.md` — 사람-AI 협업의 사실 기록
- `REQUIREMENTS_TEMPLATE.md` — 요구사항 추적표
- `DECISION_LOG_TEMPLATE.md` — 대안과 최종 채택 결정 기록
